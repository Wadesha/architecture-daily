范围默认锁死：淮海经济区核心区 = 鲁南（枣庄/临沂/济宁/菏泽）+ 苏北（徐州/宿迁/连云港）+ 皖北（宿州/淮北/亳州/阜阳）+ 豫东（商丘/周口/开封）。

① 广撒网 · 持续搜淮海古村游记（主提示词，反复用）

请帮我系统搜索【淮海经济区核心区：鲁南（枣庄/临沂/济宁/菏泽）、苏北（徐州/宿迁/连云港）、皖北（宿州/淮北/亳州/阜阳）、豫东（商丘/周口/开封）】范围内的传统村落 / 古村落游记。 不要只找一个村，要尽可能覆盖这一区域内不同县市的古村：石板房村（山亭）、各地石头部落、历史文化名村、中国传统村落名录里的村庄等。 搜到每篇后，先按"是否聚焦主题本身"给它分级打标（这是最重要的动作，别一锅炖）： 【A级 · 聚焦主题】真正的古村游记 / 田野记录——作者走进村子写乡土面貌、建筑、人情，第一人称在场，或带人名原话与营造细节。这才是我们要的。 【B级 · 夹带硬事实】表面是特殊用途（官方通稿 / 非遗申报 / 政务宣传 / 景区运营 / 民俗活动报道 / 规划报告），但里面夹着可核实的硬事实碎片（实测尺寸、建村年代、人物、制度、营造工艺）。可入库，但只淘硬事实，不当游记用。 【C级 · 沾边跑题】提了这个村/这片地方，但通篇是抒情套话、宣传语、民宿推荐、个人无信息量感慨，无硬事实可捞。筛掉，不进库。 【D级 · 明确排除】无地名无人名无数据的 AI 水文、纯营销、拼凑转载、与淮海古村无关的蹭热度内容。直接丢。 注意：C、D 级会很多很杂，这正是"相关性强但内容不够好"的滥竽——不要因为它们提到了鲁南/古村就当作游记收进来，要按上面的 A/B/C/D 分级压住，别让它们淹没 A 级好素材。 每轮至少给我一批（尽量多）候选，先按 A/B/C/D 分四组输出，每组内列出：村名 | 所在县市 | 标题 | 公众号/媒体 | 日期 | 链接 | 级别。 A、B 级抓得到的把全文要点也贴出。C、D 级只列标题+链接一句话带过即可，不用贴全文。 没搜到就说没搜到，别编村名凑数。

② 只抓某一批的"全文+链接清单"（作为入库预备）

把上面搜到的所有古村游记，整理成一份清单，每行一条： 村名 | 所在县市 | 标题 | 媒体/公众号 | 日期 | 完整链接 | 一句话要点（有无人名原话 / 有无营造细节 / 有无实测尺寸） 按"鲁南 / 苏北 / 皖北 / 豫东"分四组。 链接必须给完整的 URL（含 http/https），我要拿去批量入库，别省略或只给标题。

③ 抓某一篇的完整正文（拿到链接/标题后）

请抓取这篇公众号文章的完整正文：【标题或链接】。 我要引用里面的【人名原话 / 建筑尺寸 / 年代 / 营造工艺】，请把相关段落原样贴出，不要改写、不要概括。 若抓不到全文，直接告诉我卡在哪（找不到 / 需关注 / 已删除 / 被反爬），不要拿别的内容冒充。 抓不到就说抓不到。

④ 把单篇加工成"硬事实素材卡"（按我们写作铁律）

把上面这篇古村游记，按古村落写作的取材标准加工成素材卡： 1. 抽出可被第二人到现场核实的硬事实：年代、人物、地名、尺寸、名物、制度、营造工艺，逐条引用原文并注明出处； 2. 把上面这些与"作者个人感受 / 抒情 / 第一人称情绪"分开列出，后者标注为文体内容、不当史料； 3. 信息存疑或与已知来源矛盾的项单列标注"存疑待核"，不要自行统一成一种说法； 4. 判断这篇值不值得入库：有没有人名原话？有没有实地走访证据？有没有营造细节？没有就直说"这篇无独立信息量，不建议入库"，别为凑内容保留不可核实信息。

⑤ 单村补史实缺环（写作前，调分省方志库）

我要写【某村】的田野稿。请在我的分省方志 / 文史库（山东/江苏/安徽/河南等）里，检索该村或所属县、镇的古籍方志记载： - 建村年代与族谱源流 - 历史人物与事件 - 传统营造 / 水利 / 聚落形态的相关记载 凡检索到的方志原文，逐条引用并注明是哪部志书、什么版本。 检索不到就明确说没有，不要用后世的公众号套话来充数。

⑥ 拿不准就复核 · 逐篇判定该不该留

下面这【N】篇都提到了鲁南 / 淮海古村，相关性看着都强，但很多是官方通稿、宣传文、申报材料这类"特殊用途"内容，不是古村游记本身。请逐篇给我判定结果，别笼统说"都挺好"。 对每篇按 4 级归类，给一句话理由： 【A级 · 聚焦主题】真游记 / 田野记录，值得当游记入库； 【B级 · 夹带硬事实】虽是通稿/申报/宣传，但夹着可核实的实测尺寸、建村年代、人物、营造工艺 → 只淘硬事实，可入库； 【C级 · 沾边跑题】只提了名字，通篇套话 / 抒情 / 宣传语，无硬事实可捞 → 不进库； 【D级 · 明确排除】AI 水文 / 纯营销 / 拼凑转载 / 无关 → 丢。 判定铁律： - 它"像不像游记"取决于有没有作者在场、有没有乡土面貌描写，不是看标题有没有"古村"； - 官方/申报文里如果有"主房面阔几间、墙厚几米、建于某年"这种数字，那按 B 级留，别因为它不是游记就整篇丢； - 分不清该进哪级时，标"拿不准"，并在理由里说明你纠结的点，我来定。 输出格式：每篇一行 → 标题 | 判定级别 | 一句话理由。

⚠️ 铁律提醒（写进每条提示词的底层约束）

  • 硬事实绝不虚构：年代/人物/尺寸/名物/制度必须能被第二人现场核对；只有作者本人在场才知道的（感官、抒情、第一人称路线）才算文体内容。
  • 宁可短、不可编：搜不到就省略，不许为了凑数捏造村名或数据。
  • 矛盾并存、不擅自合并：几处来源说法打架时（建村年代、石板厚度、房屋间数），并列标注，交回人工裁决。
  • 区分事实与抒情：游记里"作者觉得/心里一酸"这类是文体材料，不是史料。
  • 分级压住滥竽：相关 ≠ 聚焦。搜到"提了古村但其实是通稿/宣传/申报/抒情"的，按 B/C/D 归级，不许混进 A 级游记。宁可 A 级少而精，不要一锅炖。

🔄 完整工作流（Copilot 抓 → 我入库 → 写作回源）

  1. 你在 ima Copilot 反复发 提示词①（广撒网）→ 它按 A/B/C/D 四级分组输出，A 级游记、B 级夹带硬事实优先看，C/D 级粗扫即可。
  2. 拿不准某篇该不该留 → 发 ⑥ 让它逐篇复核判定，它标"拿不准"的由你拍板。
  3. 把 Copilot 给的A、B 级链接清单粘贴回 WorkBuddy 对话 → 我用 import_urls 批量存进「淮海素材」库（≤10条/次，存完可检索可回源）。B 级入库时我会在文件名/备注标"仅淘硬事实"。
  4. 纯微信原生、无公开 URL 的正文，直接把文字贴我 → 我整理成文件用 create_media 入库。
  5. 写某村前：①在「淮海素材」search_knowledge 捞该村材料 → ⑤调分省方志库补史实 → 本地动笔模仿稿。
  6. 成品 HTML 快照进「古村落写作备份」库（历史备份，本地仍最新）。

为什么抓完要转我入库：ima Copilot 擅长"搜+读+整理成文字"；但"把某条真写入知识库、留下可回源的 media_id"这一动作，稳定执行要靠 WorkBuddy 的 ima MCP（import_urls / create_media→COS→add_knowledge 均已实测跑通）。所以 Copilot 负责广撒网产出清单，我负责真入库。
